# Duofin support

Duofin is an independent, free, open-source Jellyfin client designed for iPhone Duo, based on Swiftfin. You need a compatible Jellyfin server and an account on it. Duofin does not provide a subscription media catalogue.

Use the server address supplied by your server administrator. Use HTTPS for remote connections. If playback fails, check the server's transcoding settings and try the other player engine in the app settings.

Report Duofin issues at https://github.com/juicecultus/Duofin/issues or email hello@ratedcounsel.com. Include your app/iOS versions, Duo pose, player engine and reproduction steps. Remove passwords, tokens and private information from logs and screenshots.

Duofin is not an official Jellyfin application. Its changes and source are available under MPL 2.0; upstream notices and dependency licences are retained.
